# Selatara Heat

Selatara Heat is an original open-world crime game set in a tropical strait port city, built for the [“Make GTA 6” bounty on make.fun](https://make.fun/bounty/gta6-01). You play as Raka, a driver for the Arus Syndicate, working through 8 story missions across 6 districts and an offshore island: street races, a masked heist with a real crew, police chases with roadblocks and helicopter support, and a finale that boards a ferry and sails it out of the port.

Everything is original: the city, districts, characters, vehicles, brands, and story were created for this game. It runs fully offline in a desktop Chrome browser from static files — no network requests, no build step for the game itself.

## How to run

Open `game/index.html` in a desktop Chrome browser, or serve the folder with any static file server and open `game/index.html` from there.

## Controls

- **WASD / arrow keys** — move / drive
- **Mouse** — camera, **click** — shoot
- **E** — enter / exit vehicles, interact
- **Shift** — sprint
- **M** — full city map

## What is in the game

- A full city: 6 districts plus Pulau Seberang island, joined by a causeway and a working ferry
- 8 story missions with dialogue, objectives, and a career record screen
- A wanted system with patrol cars, roadblocks, and an air unit, all reported live on the HUD
- Cars with damage states, carjacking, shops with real prices, and a save-free session record of cash, missions, and cars stolen
